# Data Structures Programs 📚

Welcome to my repository! This is a collection of programs I am writing to practice and learn core Data Structures concepts. 

## 📂 What's Inside?

* **Stack** – Standard push, pop, and peek operations.
* **Queue** – FIFO (First In, First Out) queue implementations.
* **Linked List** – Creating nodes, inserting, and deleting elements.
* **Other Concepts** – Trees, Graphs, and sorting algorithms (coming soon).

## 🛠️ Language Used
* Written in: Python / C

## 🚀 How to Use
1. Download or clone this repository.
2. Open the files in your favorite code editor (like VS Code).
3. Run the programs to see how they work!
